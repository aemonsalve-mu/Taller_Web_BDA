Ciclo de evolución web

Abre las cuatro versiones del panel de seguimiento del Reto 10. Compara el salto entre etapas y cambia de versión desde su cabecera.

Guía para comparar y editar el código

HTML y árbol DOM

El navegador lee el HTML y construye el DOM. Inspecciona la tarjeta con F12 y compara el árbol de Elementos con el archivo fuente. Los encabezados nombran niveles de contenido. El CSS decide su tamaño.

ElementoDecisión de estructura
head y bodyMetadatos, título, estilos y scripts en el primero. Contenido de la página en el segundo.
header, nav, main, footerPresentación, navegación, contenido principal y cierre. Una página puede tener un encabezado interno dentro de un article.
h1, h2, h3En este laboratorio, el tema de la página, los capítulos y sus subtemas. Mantén niveles consecutivos al anidar.
section y articleAgrupa un tema con título o identifica un contenido autocontenido, respectivamente.
div y spanAgrupaciones genéricas para estilo o programación. div agrupa bloques y span suele delimitar texto en línea.
ul, ol, li y dlElementos sin orden, pasos ordenados y pares término–descripción con dt y dd.
a y buttonNavegar a una URL o a un ancla y ejecutar una acción en la página, respectivamente.

CSS, herencia y cascada

          
Un selector identifica elementos. Una propiedad heredable puede tomar el valor calculado del padre cuando el hijo carece de una declaración propia. La cascada resuelve reglas que compiten por la misma propiedad del mismo elemento.

          
.ficha li   { color: navy; }   /* cualquier li descendiente */
.ficha > ul { margin: 0; }     /* solo un ul hijo directo */
h2 + p      { margin: 0; }     /* p inmediatamente posterior a h2 */
h2 ~ p      { color: navy; }   /* hermanos p posteriores a h2 */

          
Experimentar con reglas en conflicto

          
El párrafo hereda el color del padre. El span usa una regla propia. Activa cada casilla y observa el color calculado.

MecanismoQué comprobar en DevTools

              
                
Herenciacolor y, normalmente, font-family pasan al descendiente. margin, padding, border y background-color tienen su propio valor. El fondo transparente permite ver el del padre.

                
Especificidad y ordenA igualdad de origen, importancia y capa, compara ID, clase y etiqueta. Si empatan, en estos ejemplos gana la última regla. Revisa la declaración tachada en Estilos.

                
Modelo de cajaContenido, relleno, borde y margen. Con box-sizing: border-box, el ancho especificado incluye relleno y borde.
